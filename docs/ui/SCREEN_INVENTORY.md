# Инвентарь экранов (Уровень 1 — Screen Map)

Часть UI-спецификации Banking Shell. Общая схема — в [UI_ARCHITECTURE.md](UI_ARCHITECTURE.md).

**Источник:** схема User Flow из референса R38, файл [`refs/R38-user-flow.jpg`](../../refs/R38-user-flow.jpg).
На схеме платежи сделаны на UPI (Индия). По решению [D-01] UPI заменён на **СБП**: подписи узлов на схеме остались английскими, а ID и названия экранов — уже под СБП.
Всё, чего нет на схеме, помечено как `UNKNOWN` или `[A]`. Такие пункты не считаются требованиями.

**Легенда:**

| Метка | Значение |
|---|---|
| `[S]` | Взято из схемы |
| `[A]` | Допущение или предложение, требованием не является |
| `[R]` | Взято из [`ROADMAP.md`](../../ROADMAP.md), на схеме этого нет |
| `[D-xx]` | Принятое решение. Журнал решений — в [UI_ARCHITECTURE.md](UI_ARCHITECTURE.md#журнал-решений) |
| `UNKNOWN` | Схема этого не описывает |

**Статусы экранов:**

| Статус | Значение |
|---|---|
| `CONFIRMED` | Узел схемы, который является экраном. Содержимое при этом может быть неизвестно |
| `CANDIDATE` | Узел схемы без исходящих связей. Непонятно, отдельный ли это экран, поэтому не подтверждён |
| `CANDIDATE / NAVIGATION GROUP` | Кандидат, который скорее группа пунктов навигации, чем экран (SBP-02) |
| `DUPLICATE` | Повтор узла, который уже учтён. Отдельного экрана не получает |
| `FLOW_NODE` | Не экран: начало, решение, переход, действие, метка ребра |

## 2. Сводка по экранам

- **Всего ID экранов: 36.**
  - **CONFIRMED — 29:** AUTH-01…07, HOME-01…04, ACC-01, ACC-02, ACC-03, ACC-07, PAY-01…04, PAY-06, SBP-01, SBP-03, CARD-01, SVC-03, NOTIF-01, SET-01…04.
  - **CANDIDATE — 7:** ACC-04, ACC-05, ACC-06, SVC-01, SVC-02, SVC-04, SBP-02 (группа навигации).
- **Исключён [D-06]:** N45 Pay to UPI ID (бывший PAY-05). ID PAY-05 больше не используется.
- **Дубли** (узлы без своего ID): N29 → CARD-01, N35 → PAY-01, N36 → PAY-03.
- **Не экраны:**
  - N01 Start;
  - решения D1 (N02) и D2 (N03);
  - переход N11 «Take user to home page»;
  - действие N42 Logout;
  - глобальный компонент N19 Bottom Navigation Bar;
  - пункт навигации N34 Go to Home;
  - метки рёбер YES, NO, Success, Failure.
- **Откуда 36.** В исходном списке задачи 36 экранов. Добавлен узел N38 **UPI Functions** (теперь SBP-02): он есть на схеме, но в списке его не было. Убран Pay to UPI ID [D-06].
- **Переименования по [D-01] и [D-04]:** PAY-07 UPI → **SBP-01 СБП**; PAY-09 UPI Functions → **SBP-02 Функции СБП**; PAY-08 Register UPI → **SBP-03 Подключение СБП**. СБП — часть домена платежей (PAY), отдельным бизнес-доменом не считается.
- **Зарезервированные разделы [D-05]:** кредитная карта, кешбэк и накопления. Экранов пока нет, см. [раздел 3.1](#31-зарезервированные-разделы).
- **Предложенные состояния флоу.** PST-01 — подтверждение платежа, PST-02 — результат платежа, PST-03 — ошибка входа. На схеме их нет, в инвентарь они **не входят** и описаны в [USER_FLOWS.md](USER_FLOWS.md#предложенные-состояния-флоу).

### 3.1 Зарезервированные разделы

По решению [D-05] под эти разделы из ROADMAP (этапы 5–7) оставлено место. Экраны **проектируются отдельно**, в счёт 37 экранов не входят.

| Префикс ID | Раздел | Источник |
|---|---|---|
| `CREDIT-xx` | Кредитная карта: лимит, льготный период, рассрочка | ROADMAP, этап 5 [R] |
| `CASHBACK-xx` | Кешбэк: категории, уровни | ROADMAP, этап 6 [R] |
| `SAVE-xx` | Накопления: копилки, накопительный счёт | ROADMAP, этап 7 [R] |

Где они появятся в навигации (скорее всего, в HOME-04 Menu), решится при их проектировании.
